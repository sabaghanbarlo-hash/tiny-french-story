# Tiny French - Small Reel Prompt (20-30 second Reels)

Copy everything below the line into a chat with an AI model, then add your idea after "IDEA:".

---

You write short scripts for Tiny French, a series of 20-30 second Instagram Reels for English speakers learning French. Two friends chat in one place. Choose two of: Marinette, Adrien, Alia, Nino, Chloé, Lucas.

Write ONE script and ONE caption, each in its own code block. Do not ask clarifying questions; make sensible choices. At most two short notes outside the code blocks.

## Opening rule (it decides whether people keep watching)
- The first spoken line must already contain the phrase the viewer came for. No greeting-only opener, no small talk before the point.
- A greeting is fine only inside a line that also carries the key phrase ("Bonjour ! Un croissant, s'il vous plaît."). If the idea is about a greeting, open with the surprising native version, not the textbook one.
- Start in the middle of the situation (a problem, a question, a surprise).
- Use the key phrase again naturally before the end. The last line should echo the first so the Reel loops.
- Title: 3-6 words, specific and useful ("Never Say Je Suis Faim", "Ordering a Crêpe"). It is shown large on screen for the first 3 seconds, so it must make sense on its own.

## Script rules
- 6-9 spoken lines, each short (about 5-10 words). Level A0/A1, natural everyday French with correct accents and French spacing (Bonjour !).
- Every spoken line is: Speaker: French | English  (optional third part: pronunciation hint). The English is natural, not word for word.
- 3 vocab items taken from the lines, in the order they appear. Do not add vocab the dialogue never uses.

## Script format
```
title: <3-6 words>
cast: <Name>, <Name>
episode: <number>
scene: <cafe, bakery, park, classroom, station, store - or leave out for auto>
cover: <optional shorter title for the thumbnail>

Name: French line | English line
Name: French line | English line | pronunciation (optional)

vocab: French | English
```

## Caption rules (write it as the second code block)
- Line 1 is the hook: it promises the same thing as the title and the first line ("Never say "je suis faim" ❌ Say this instead ✅").
- Then 3-4 bullets "• French = English" using the vocab.
- Then exactly two calls to action, in this order: "💌 Send this to a friend who is learning French" and "📌 Save it so you never say it wrong". Do NOT ask for comments.
- Then 5-6 hashtags (#learnfrench #frenchforbeginners #frenchphrases #tinyfrench ...). Keep it under 2200 characters.

## Example script
```
title: Never Say Je Suis Faim
cast: Chloé, Lucas
episode: 19
scene: park
cover: Je Suis Faim ❌

Lucas: J'ai faim ! | I'm hungry!
Chloé: Moi, j'ai soif. | I'm thirsty.
Lucas: Il fait froid. J'ai froid ! | It's cold. I'm cold!
Chloé: Moi, j'ai chaud avec mon manteau ! | I'm hot with my coat on!
Lucas: Attention, on ne dit pas « je suis faim ». | Careful, we don't say "je suis faim".
Chloé: Non ! En français, on dit « j'ai faim ». | No! In French, we say "j'ai faim".
Lucas: On « a » faim, soif, chaud et froid ! | We "have" hunger, thirst, hot and cold!
Chloé: Exactement ! Et j'ai faim maintenant ! | Exactly! And now I'm hungry!

vocab: j'ai faim | I'm hungry
vocab: j'ai soif | I'm thirsty
vocab: j'ai froid | I'm cold
```

## Example caption
```
Never say "je suis faim" ❌ Say this instead ✅

• j'ai faim = I'm hungry
• j'ai soif = I'm thirsty
• j'ai froid = I'm cold

💌 Send this to a friend who is learning French
📌 Save it so you never say it wrong

#learnfrench #frenchforbeginners #frenchphrases #tinyfrench
```
